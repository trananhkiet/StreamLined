## Vì sao chọn ResNet110 → ResNet32
- Có trong bảng paper (README): teacher 74.31; SKD **74.84**; KD 74.01; DKD 74.12; MLKD 74.24.
- Cùng họ CIFAR-ResNet → chỉ cần thêm độ sâu 110/32 (`CifarResNet`), không viết kiến trúc mới.
- Teacher mdistiller `cifar_teachers/resnet110_vanilla/ckpt_epoch_240.pth`: SHA-256 `75dc04fa…41a9`, accuracy lưu trong checkpoint
  **74.31%** = số teacher của paper (nạp `strict` vào `CifarResNet(110)`: 1.737M tham số). Script tự dừng nếu teacher < 74.0% trên test.

## Thay đổi code (mặc định giữ nguyên ResNet56 → ResNet20)
`TEACHER_ARCH` (resnet56 | resnet110), `STUDENT_ARCH` (resnet20 | resnet32); `MDISTILLER_TEACHERS` theo kiến trúc (tar member, SHA-256,
ngưỡng top-1). `TEACHER_SOURCE=skd` chỉ hỗ trợ ResNet56. Tên file checkpoint student giữ `resnet20_skd_best.pth` (chỉ là tên file).
Test `kaggle/test_arch_r110_r32.py` — PASS: mặc định khởi tạo ResNet20 + loss F1b bit-exact bản trước; ResNet110/56 thật nạp strict;
SHA-256 qua đúng hàm nạp; skd + ResNet110 báo lỗi; 3 bước train F1b ResNet110 → ResNet32 chạy được.
